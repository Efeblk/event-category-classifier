What would you like to do?

Tell us in Turkish or English. This small prototype classifies your request as concert, theatre, stand-up, or unclear.

Describe your plan

A small part of event discovery

  1. Read one request in Turkish or English.
  2. Predict the activity category.
  3. Ask for a clearer request when no single category is supported.

The course experiment compares Naive Bayes, Logistic Regression, and a linear Support Vector Machine. Simple rules check explicit exclusions and requests for multiple categories.

Prototype data: generated requests. The results do not establish accuracy on real users. Translations and paraphrases stay in the same data partition.

This prototype classifies one request. It does not find events or apply date, location, or budget filters. The unclear category also covers unrelated requests. An ambiguous prediction can still be wrong.

Local course demonstration. Predictions use the trained model on this computer. No paid AI API.
