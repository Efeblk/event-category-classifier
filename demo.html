What kind of event is this?

A small part of event discovery. This model reads a Turkish event title and description. It predicts concert, theatre, or stand-up.

Try an event description

How the model works

  1. Normalize Turkish text.
  2. Convert text to TF-IDF features. The experiment tests words and word pairs. TF-IDF measures how useful each term is in the dataset.
  3. Use the model with the best validation result.

The experiment compares Naive Bayes, Logistic Regression, and a linear Support Vector Machine. A majority-class baseline gives a simple reference.

The test data stays separate during model selection. Repeated event families stay in one data partition.

This model always selects one of three categories. It cannot reject unrelated text. It does not search events, check tickets, or measure event quality. The sample descriptions are new demonstration text. They are not test results.
